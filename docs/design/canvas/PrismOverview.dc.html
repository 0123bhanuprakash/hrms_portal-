Same rules as Signature
  • Behind content only; cards, tables and charts stay solid.
  • Slow (nothing faster than 7 s), soft (≤ 35% dark / 22% light).
  • Theme colours recolour every mood; status colours stay semantic.
  • Lively / Calm / Off and “Reduce motion” work the same.
What changes with Prism
  • Home: Aurora → Light beams
  • People: Constellation → Bauhaus shapes
  • Attendance: Light sweep & dial → Chronograph
  • Leave: Calm horizon → Striped sun
  • Projects: Blueprint spotlight → Isometric build
  • Expenses: Emerald mesh → Facets
  • …and 7 more (see the rows below)
Build notes
  • Same <PageBackdrop/>; mood = pack + section, e.g. data-pack="prism" data-mood="home".
  • New CSS only (.p-* classes); no libraries, no canvas/WebGL.
  • Phones: half the particles; low-power devices get the still frame.
  • 3D cubes and grid plane use CSS 3D transforms only.
