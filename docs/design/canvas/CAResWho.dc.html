Edge cases (our default)

• Same person is PM and DD → the DD step is skipped automatically.
• DD is also PMO → the PMO step is skipped (DD can assign anyone).
• Project has no DD → PM approves straight to PMO.
• Approver on leave → delegation (existing) applies.
• Nobody can approve their own request.
