Same rules as Signature
  • Behind content only; cards, tables and charts stay solid.
  • Slow (nothing faster than 7 s), soft (≤ 35% dark / 22% light).
  • Theme colours recolour every mood; status colours stay semantic.
  • Lively / Calm / Off and “Reduce motion” work the same.
What changes with Terra
  • Home: Aurora → Time-of-day sky
  • People: Constellation → Fireflies
  • Attendance: Light sweep & dial → Sun path
  • Leave: Calm horizon → Clouds & hills
  • Projects: Blueprint spotlight → Contour map
  • Expenses: Emerald mesh → Dappled light
  • …and 7 more (see the rows below)
Build notes
  • Same <PageBackdrop/>; mood = pack + section, e.g. data-pack="terra" data-mood="home".
  • New CSS only (.t-* classes); no libraries, no canvas/WebGL.
  • Phones: half the particles; low-power devices get the still frame.
  • Home sky reads the company time zone once a minute.
